Entry for the [Invent a Word We Need](https://make.fun/c/u-deranalabs-invent-a-word-we-need-17a020e0) competition on make.fun: one newly coined English word, defined in a single clear line of at most 140 characters. It names the frantic pocket check everyone does before leaving the house — a small daily ritual English somehow never named.

**The entry:** pocketpat (n.) the frantic pat-down of every pocket for phone, keys and wallet before you can leave the house.

Entry length: 110 characters (gate: 1–140).

## How to run

```sh
python3 main.py
```

This writes the entry to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set). The program validates the 140-character gate and exits non-zero if the entry is outside it. Python 3.13 standard library only; deterministic, no network access, no randomness.
